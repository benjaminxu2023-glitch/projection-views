# 投影与视图 · 3D 教学（v2）

Designed by Benjamin Xu

一个手机浏览器里就能用的「投影与视图」3D 教学网页：三个互相垂直的投影面（正面 V、侧面 W、水平面 H）围成墙角，蓝色几何体放在中间，三面墙上实时显示它的投影，可以叠加三视图（看得见的线画实线、被挡住的线画虚线），也可以把三个投影面展开成平面上的三视图。

## 怎么用

- **单指拖动**：旋转视角；**双指捏合**：缩放；**双击场景**：视角复位（电脑上鼠标拖动 + 滚轮）。
- 点底部的控制台展开：
  - **几何体**：45 种，全部免费。
  - **投影光源模式**：平行光（正投影）/ 点光源（中心投影）。
  - **三视图**：叠加显示三视图（实线 = 可见轮廓，虚线 = 不可见轮廓）。
  - **手动变换**：绕 X / Y / Z 轴旋转物体（-180° ~ 180°），一键复位。
  - **更多**：展开三视图、显示投射线、显示投影、显示坐标轴、视角复位。
- 点光源模式下，每个投影面前方各有一个发光的投射中心，可以调「距离 / 左右 / 上下」，面板里会显示物体中心截面的放大倍数。

直接打开：

- 单文件版：`dist/projection-views-standalone.html`（不需要联网、不需要服务器，双击或发到手机上就能打开）。
- 源码版：在仓库根目录 `npm run serve`，然后打开 `http://<电脑IP>:8080/`。

## 45 种几何体

- **基本体**（5）：正方体、长方体、圆柱、圆锥、球
- **棱柱**（5）：正三棱柱、正四棱柱、正五棱柱、正六棱柱、正八棱柱
- **棱锥**（5）：正三棱锥、正四棱锥、正五棱锥、正六棱锥、正四面体
- **台体与多面体**（5）：正三棱台、正四棱台、正六棱台、圆台、正八面体
- **回转体**（6）：半球、半圆柱、圆环、圆管、胶囊体、斜截圆柱
- **切割体**（8）：楔形块、斜切长方体、切角长方体、倒角长方体、工字形块、带腰形孔板、V 形槽块、燕尾槽块
- **组合体**（11）：L 形块、T 形块、U 形块、两级台阶、三级台阶、十字形块、带圆孔方块、带方孔方块、圆头带孔板、圆柱叠方块、轴承座

## 实现要点

- 世界坐标 Z 轴向上，V 面 y=0、W 面 x=0、H 面 z=0，按第一角画法布置；展开时 H 面绕 X 轴向下转 90°，W 面绕 Z 轴向右转 90°。
- **投影是精确的**：每面墙离屏渲染一张 1024² 遮罩（4×MSAA），在顶点着色器里把物体网格直接投到墙面坐标（正投影或中心投影 t = n·L / (n·L − n·p)），三角形重叠处取并集，所以不会出现重叠变深；再做两次高斯模糊得到柔和边缘。
- **三视图虚实线**在 CPU 上算：把每条特征棱分段采样，判断是否被前面的三角形挡住（自带网格加速），曲面只画轮廓线。
- 按需渲染（只有变化时才重画），像素比最高 2，移动端 60fps。
- Three.js r160 和需要的 addons 都放在 `vendor/` 里，不用 CDN。

## 开发

```bash
npm test            # 投影数学（正投影、中心投影手算值、放大倍数、旋转矩阵）+ 45 种几何体（封闭、体积、三视图）
npm run build       # 生成 app.min.js 和 dist/projection-views-standalone.html
npm run shots       # Playwright 390×844 触屏截图到 docs/screenshots，并检查控制台错误
```

## 已知限制

- 点光源模式下，三个投影面各用一个投射中心（同一个点光源不可能同时在三面墙上都投出完整的像，会有一部分落到墙外）。
- 三视图虚线是逐段采样判断的，非常细小的遮挡交界处可能有一两段长度的误差。
- 曲面体（球、圆环等）用多边形近似，轮廓线是近似的。
