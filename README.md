# 投影与视图 · Projection & Views

作者：**Benjamin Xu**

一个面向手机浏览器的 3D 交互教学页面，用来演示**正投影（平行光）**、**中心投影（点光源）**和**三视图**（第一角画法，GB/T 14692）。纯静态文件，无需后端、无需登录、全部 45 种几何体免费使用。

## 功能

- **三投影面体系**：V 面（主视图，正立面）、H 面（俯视图，水平面）、W 面（左视图，侧立面），按第一角画法放置，带网格、中文标注和 X / Y / Z 轴。
- **两种光源**
  - 平行光：正投影，影子与物体等大。
  - 点光源：中心投影，光源位置可见、可用滑块调节，实时显示三个面上的放大比（光源到投影面的距离 ÷ 光源到物体中心截面的距离）。光源离得太近或跑到物体后面时，会跳过无法投射的面并给出提示，不会出现错误图形。
- **实时投影**：红色半透明投影，模板缓冲避免重叠三角形叠色，超出投影面的部分在 CPU 端裁掉。
- **叠加三视图**：可见轮廓线画粗实线，不可见轮廓线画虚线，逐段做遮挡判定（例如带圆孔方块的孔在主视图、左视图里显示为两条虚线）。
- **展开三视图**：H 面绕 OX 轴向下转 90°，W 面绕 OZ 轴向右转 90°，得到"主视图在上、俯视图在下、左视图在右"的标准布局。
- **物体旋转**：X / Y / Z 三个滑块（−180°～180°，显示度数），一键复位。
- **视角**：单指旋转、双指缩放（鼠标拖动和滚轮同样可用）；预设"默认 / 正对主视图 / 正对俯视图 / 正对左视图"。
- **可折叠底部面板**：点击或上下滑动把手展开或收起；面板展开时 3D 场景自动在可见区域内居中。
- **移动端优化**：像素比上限为 2、无阴影贴图、`touch-action: none`、适配安全区（刘海和 Home 指示条）。

## 使用

ES 模块不能从 `file://` 加载，所以本地预览要起一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

如果想要双击就能打开的单文件版本：

```bash
npm run build   # 生成 dist/projection-views-standalone.html
```

URL 参数（方便分享某个状态）：`?solid=holeblock&views=1&mode=central&rays=1&unfold=1&rot=20,-15,35&panel=1`

## 测试

```bash
npm test        # Node 内置测试运行器（node --test），无需安装依赖
```

- `test/projection.test.js`：平行投影和中心投影坐标与手算结果对照、共线性、放大比、点在投影面上、光源在物体后面等退化情况、Euler 旋转矩阵与 Three.js 一致、矩形裁剪、整体网格投影面积。
- `test/solids.test.js`：45 种几何体 id 和名称唯一；逐个检查有限值、包围盒归一化、网格闭合（每条边恰好被两个三角形反向共享）、体积为正；另外检查典型三视图的虚线数量（如带圆孔方块、轴承座、U 形槽块）。


## 说明

- 本项目为**独立实现**：界面、代码和几何数据全部重新编写，没有使用任何现有 App 的代码、素材或文案。
- 3D 渲染使用 [Three.js](https://threejs.org/) r160（MIT 许可证），通过 jsDelivr 固定版本加载。
- 已知限制：曲面体用多边形网格近似，旋转后曲面的轮廓线可能有轻微折线感；视图中暂不绘制中心线；页面需要联网加载 Three.js。
