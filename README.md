# 投影与视图 · 3D 教学（v2）

Designed by Benjamin Xu

一个手机浏览器里就能用的「投影与视图」3D 教学网页：三个互相垂直的投影面（正面 V、侧面 W、水平面 H）围成墙角，蓝色几何体放在中间，三面墙上实时显示它的投影，可以叠加三视图（看得见的线画实线、被挡住的线画虚线），也可以把三个投影面展开成平面上的三视图。

## 怎么用

- **单指拖动**：旋转视角；**双指捏合**：缩放；**双击场景**：视角复位（电脑上鼠标拖动 + 滚轮）。
- 点底部的控制台展开：
  - **几何体**：45 种，全部免费。
  - **投影光源模式**：平行光（正投影）/ 点光源（中心投影）。
  - **三视图**：叠加显示三视图（实线 = 可见轮廓，虚线 = 不可见轮廓）。
  - **手动变换**：绕 X / Y / Z 轴旋转物体（-180° ~ 180°），一键复位。
  - **更多**：展开三视图、显示投射线、显示投影、显示坐标轴、视角复位。
- 点光源模式下，每个投影面前方各有一个发光的投射中心，可以调「距离 / 左右 / 上下」，面板里会显示物体中心截面的放大倍数。

直接打开：

- 单文件版：`dist/projection-views-standalone.html`（不需要联网、不需要服务器，双击或发到手机上就能打开）。
- 源码版：在仓库根目录 `npm run serve`，然后打开 `http://<电脑IP>:8080/`。

## 45 种几何体

- **基本体**（5）：正方体、长方体、圆柱、圆锥、球
- **棱柱**（5）：正三棱柱、正四棱柱、正五棱柱、正六棱柱、正八棱柱
- **棱锥**（5）：正三棱锥、正四棱锥、正五棱锥、正六棱锥、正四面体
- **台体与多面体**（5）：正三棱台、正四棱台、正六棱台、圆台、正八面体
- **回转体**（6）：半球、半圆柱、圆环、圆管、胶囊体、斜截圆柱
- **切割体**（8）：楔形块、斜切长方体、切角长方体、倒角长方体、工字形块、带腰形孔板、V 形槽块、燕尾槽块
- **组合体**（11）：L 形块、T 形块、U 形块、两级台阶、三级台阶、十字形块、带圆孔方块、带方孔方块、圆头带孔板、圆柱叠方块、轴承座

## 实现要点

- 世界坐标 Z 轴向上，V 面 y=0、W 面 x=0、H 面 z=0，按第一角画法布置；展开时 H 面绕 X 轴向下转 90°，W 面绕 Z 轴向右转 90°。
- **投影是精确的**：每面墙离屏渲染一张 1024² 遮罩（4×MSAA），在顶点着色器里把物体网格直接投到墙面坐标（正投影或中心投影 t = n·L / (n·L − n·p)），三角形重叠处取并集，所以不会出现重叠变深；再做两次高斯模糊得到柔和边缘。
- **三视图虚实线**在 CPU 上算：把每条特征棱分段采样，判断是否被前面的三角形挡住（自带网格加速），曲面只画轮廓线。
- 按需渲染（只有变化时才重画），像素比最高 2，移动端 60fps。
- Three.js r160 和需要的 addons 都放在 `vendor/` 里，不用 CDN。

## geometry-76 子应用：176 种模型，用主页同一套引擎

`geometry-76/index.html`（176 种模型：基础 76 + 进阶 100）加载的是根目录同一个 `app.min.js`：三块投影面、墙上投影遮罩、叠加三视图虚实线、平行光 / 点光源（含投射中心滑块和放大倍数）、旋 X/Y/Z、展开三视图动画、投射线 / 投影 / 坐标轴开关、视角复位 / 双击复位、URL 参数（`?solid=mech-012&views=1&unfold=1&rot=…&mode=central&light=…`，旧链接的 `?model=` 也认）和 `window.__pv` 调试对象，全部与主页一致。只有「几何体」一节换成模型库面板：模型范围（进阶 100 / 基础 76 / 全部 176）、考点分类、搜索、上一题 / 随机 / 下一题、练习卡（题号、难度、题目、结构分析提示、教材来源链接）。

- 接入方式：页面在加载 `app.min.js` 之前由 `geometry-76/library.js` 提供 `window.PV_LIBRARY`；引擎看到它就改用这 176 个模型（`src/solids.js` 的 `buildSolidFromMesh`），其余代码路径不变。主页 45 种几何体的网格、棱线和三视图结果与改动前逐字节相同（`scripts/` 里的回归比较）。
- 坐标约定：geometry-76 原数据主视图从 -Y 看、左视图从 -X 看；主页引擎主视图从 +Y 看、左视图从 +X 看（都是 Z 向上、第一角画法）。两者相差绕 Z 轴转 180°：(x, y, z) → (−x, −y, z)，再统一居中、缩放到最大尺寸 2。
- 网格转换（`src/mesh.js`）：顶点焊接（1e-5）→ 消除 CSG 的 T 形接点（把落在边上的顶点插进去，重心扇形剖分）→ 修 CSG 裂缝（只在开口边端点之间按 3e-4 再焊接 / 插点，补周长 < 1% 尺寸的小缝和整圈共面的漏面）。基础模型里“叠放”的组合体先用 `csg.js` 求并集。
- **曲面平滑阈值**（`src/solids.js` 的 `meshEdgeKind`）：主页 45 种用统一的 30°；176 个模型里有 22° 的缓坡斜切面（如 M018、M019），统一 30° 会把这些真实棱线当成曲面而丢掉，统一调小又会把粗离散的抛物面（23.3°）、圆环（22.5°）画出一圈圈假棱线。所以 `csg.js` 现在给每个圆柱面 / 球面 / 回转面打上“光滑曲面编号”，并在布尔运算中随多边形传递：同一曲面上相邻面夹角 < 40° 才算光滑（只在转向轮廓处画）；不同曲面之间夹角 < 13.5° 也算光滑（平面与 28 等分圆柱相切处最大 12.9°，制图规定相切处不画线）；其余一律是棱线。
- 剖切（半体 / 四分之一切除）这一版没有接入：主页引擎没有剖切面着色和剖面线，切掉一块后的“三视图”也不是规范的剖视图，容易误导，先不做。

## 已知限制

- 点光源模式下，三个投影面各用一个投射中心（同一个点光源不可能同时在三面墙上都投出完整的像，会有一部分落到墙外）。
- 三视图虚线是逐段采样判断的，非常细小的遮挡交界处可能有一两段长度的误差。
- 曲面体（球、圆环等）用多边形近似，轮廓线是近似的。
- geometry-76 的少数进阶模型（M015、M018、M058、M077、M099、M100）CSG 结果本身有极小的残缺或零厚度重叠面（开口边 ≤ 6 条、非流形边 ≤ 11 条），这些边按棱线处理，可能多出极短的线头。
